# Third-party software

## pyAgxArm

RURI carries the upstream Agilex Robotics `pyAgxArm` repository as the Git
submodule `vendor/pyAgxArm`, pinned to commit
`799b8412fbe8b9156bc9892d3dbeb2df7e98be71`.

- Upstream: <https://github.com/agilexrobotics/pyAgxArm>
- License: LGPL-3.0-only
- License text: `licenses/LICENSE.pyAgxArm` and `vendor/pyAgxArm/LICENSE`

The submodule is not maintained as RURI source code. Its upstream copyright
and license terms remain in effect.
